# From figure or table to its source

Every table and number in the paper is generated; nothing is typed in. `results/MANIFEST.sha256` holds a SHA-256 for each released file (`sha256sum -c results/MANIFEST.sha256`).

| Paper item | Generated by | From |
|---|---|---|
| Tab. 1 tasks, Tab. 2 sample flow | `analysis/make_tables.py` | `data/split_hashes.json`, `data/banglish_human.csv` (not released; see below) |
| Tab. 3 main accuracy, Tab. 4 d3-flash, Tab. 7 CI | `make_tables.py` | `analysis/tables/rq1_accuracy.csv` |
| Tab. 5 AI-generated Banglish, Tab. 8 per task | `make_tables.py` | `analysis/tables/human_items_paired.csv`, `human_items_all_models.csv` |
| Tab. 6 ECE and temperature, calibration appendix tables | `make_tables.py` | `rq2_calibration.csv`, `rq2_temperature_scaling.csv`, `human_items_all_models.csv` |
| Tab. rotation | `make_tables.py` | `rq4_rotation.csv` |
| Fig. 1-6 | `analysis/make_figures.py` | the same CSVs and `analysis/items.csv` |
| Every number in the text | `numbers.tex` from `make_tables.py`; checked by `analysis/audit_numbers.py` | as above |

Released: result tables (`analysis/tables/`), open-model item-level predictions (`results/predictions_open_models.csv.gz`), the AI-generated Banglish for MASSIVE and XNLI-bn (`data/banglish_ai_release.csv`), generated LaTeX tables and numbers. The predictions file has no dataset text except that Belebele's option labels are the Bengali option texts (CC BY-SA 4.0).

Not released: Jev raw responses (provider terms); SentNoB text and the Banglish of its sentences (CC BY-ND); the original generation prompts (never recorded; `docs/BANGLISH_GENERATION.md` has a retrospective reference prompt, labelled as such). The files under `data/` that the pipeline reads for the SentNoB items (`banglish_human.csv`) are therefore absent, and `make tables` cannot be fully rerun from a clone; `make audit` and `make paper` can.
