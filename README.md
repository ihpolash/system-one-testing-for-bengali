# System One decision models on Bengali

Code, result tables and AI-generated Banglish for my preprint *Decision Models on Bengali: Accuracy, Calibration and Script Robustness under Rule-Based and AI-Generated Romanization* (Ismail Hossain Polas, Jahangirnagar University, ismailhossainpolash@gmail.com).

I tested one hosted decision model (Jev), ten open decision models (the vLLM-SR d3 family, Laya, laya-bangla, Julia-1 and Kev) and a general-purpose baseline (Gemma) on five Bengali tasks, in Bengali script and in Latin letters, and compared rule-based romanization with Banglish generated by ChatGPT, corrected with Grok and Claude and reviewed by me.

> **Correction.** Earlier versions of this README, the paper source and some analysis notes (and so the git history) described this Banglish as hand-written. That was wrong: it is AI-generated and author-reviewed, never typed by a person from scratch. Nothing in this repository measures how people type Banglish. In the code and data files the internal name `human` (variant, `banglish_human*.csv`, `*_human` run folders) means this AI-generated Banglish.

## Layout
- `paper/` LaTeX source, figures, generated tables and `numbers.tex`. `main.pdf` is built with `tectonic`.
- `analysis/` metrics, table and figure scripts. `analysis/tables/` holds the result tables the paper is generated from. `audit_numbers.py` recomputes the headline numbers independently of the table script.
- `harness/` my fork of [jev-benchmarking](https://github.com/AppliedMachineLearning-Lab/jev-benchmarking) (MIT, Deußer et al.), with the Bengali tasks, the romanization variants and adapters for the open models.
- `docs/BANGLISH_GENERATION.md` how the Banglish was produced (tool versions, the correction rate, and a reference prompt that is an illustration, not the original). 
- `docs/PROMPTS.md` the exact question structure sent for each task (dataset text replaced by placeholders). Regenerate with `analysis/dump_prompts.py`.
- `kaggle/` the kernel scripts that ran the open models on Kaggle GPUs.
- `data/banglish_ai_release.csv` the corrected Bengali and the AI-generated Banglish for the MASSIVE and XNLI-bn sentences. SentNoB is CC-BY-ND, so its text and the Banglish of its sentences are not included. `data/freeze_splits.py` rebuilds the splits from the public datasets.

## What you can rerun
- `pip install -r requirements.txt`, then `make audit` recomputes the headline numbers from the committed tables and checks every released file against `results/MANIFEST.sha256`; `make paper` compiles the PDF. Both work from a fresh clone. `make test` runs the unit tests.
- `make collect tables release figures` rebuild `analysis/tables/`, the LaTeX tables, the released predictions and the figures from the raw model outputs. Those inputs (`runs/`, the Jev response cache, the 307 MB item file, the SentNoB Banglish) are not published, so these targets do not run from a clone. `docs/ARTIFACTS.md` maps every figure and table to its script and input.
- Released: result tables, open-model item-level predictions with probabilities (`results/predictions_open_models.csv.gz`; no dataset text except Belebele's option labels, CC BY-SA 4.0), checksums, and the AI-generated Banglish for MASSIVE and XNLI-bn. Not released: Jev raw responses (provider terms), SentNoB text and its Banglish (CC BY-ND), the original generation prompts (never recorded).
- `docs/MODELS.md` lists every system's identifier, revision and settings; `docs/PROMPTS.md` the question structure for each task.
- Running the models again needs a TypeSafe API key for Jev (`TYPESAFE_API_KEY`) and a Kaggle GPU for the open ones (`kaggle/`).
